# 提示词工程

下面的内容是用户经验、草稿转述和待核验研究线索，不是 Library 或 Application 的设计权威。

## 措辞的强度跟着把握走

研究线索：谄媚可能让意见随用户反应来回摆动；要求模型说明把握可能缓解，但模型自报的把握不能自动调节推理。

推断：讨论中用措辞强度表达“已推出”“推断”“猜”，不把一个未经确认的数值置信度当作前提。这是给读者的信号，不替代独立检验。

## 用立场代替命令

工作假设：人的长期记忆形成稳定意图，模型更擅长局部知识和推理；模型可能顺着命令中错误的具体做法走偏。

推断：Principal 提供方向、意图和约束，Cognizer 自己推导做法；做法与意图冲突时应报出冲突。这是协作策略，不能由提示词强制保证。

## 待验证

- 怎样判断模型抓大放小、有抽象审美，而不是凭印象选。
- 立场式表达是否比命令式表达更少被错误观点带偏。
- 措辞强度是否会让模型过度顺着更确定的语气。
