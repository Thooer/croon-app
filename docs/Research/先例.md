# 先例

借用一个先例之前，先写出它的前提，再与 Croon 的前提对照。前提对不上的部分，表里「与设计的关系」不成立。第三列只指向设计的概念，不复述规则。

## 智能体框架

| 先例 | 观察 | 与设计的关系 |
|---|---|---|
| LangGraph | 共享 state 与 reducer；checkpointer 存档，可回到某处分叉；interrupt；Send 扇出；supervisor 与 swarm | 对照：共享 state 归一个成员；回到存档对应分叉；swarm 里当前的 agent，就是谁手里有用户的回话途径 |
| OpenAI Agents SDK | handoff 与 agent-as-tool；guardrail | 交出回话途径与委托是两种关系；guardrail 是 Middleware |
| AutoGen 的 Selector、MagenticOne | 由模型选下一个发言者；编排者维护任务与进度的账本 | 群聊房间；终止条件是 Signature 所在的成员何时结束 |
| MetaGPT 的消息池 | 共享的消息池，按兴趣订阅 | 对照：订阅要持有池子的 Port，不是环境权利 |
| Claude Code 的动态工作流 | 极简的 ReAct 循环；任务超出一个对话时，模型写一份编排脚本在后台运行，上下文只留最终答案；子代理只交回摘要。Workflow 工具的原语有 agent、pipeline（每项独立流经全部阶段，没有阶段间屏障）、parallel（屏障，全部完成才返回）、budget；可恢复：前缀未变的调用直接返回缓存，所以脚本禁用时间与随机数；需要跨阶段控制流、大规模并行、可恢复时才用，一波独立子任务与强顺序依赖不用 | 动态的编排是一份 Cognition，不是 Charter。对照：这份脚本是数据，运行前能检查，能重放。对照 Lang0：并发用 ProcessPoolExecutor，把一项的多阶段写成顶层函数再 submit 就是 pipeline，result 全收就是 parallel；重放靠键，不靠前缀匹配 |
| Harness² | Agent 外侧拆成八类文件化组件，修改是可审查的 diff；任务内同模型、同环境试跑候选，按行为对照只采纳有执行证据的修改；跨任务沉淀经验，不继承上一个的配置；正确性另有独立评估；执行器默认联网，曾自行下载公开的评分 rubric | 改 Agent 的工作方式由 Principal 来做；试跑；采纳是 Handoff 给新的 Instance；Handoff 给整理过的结果；rubric 泄露对照存储不是后门 |
| AgentSquare；EvolveR；Memento-Skills | AgentSquare（arXiv:2410.06153，ICLR 2025）：规划、推理、工具、记忆作为模块化搜索空间，自动搜索比手工设计提升 17.2%。EvolveR（arXiv:2510.16079）：从自身交互历史提炼可复用的策略原则。Memento-Skills：出处待补 | Agent 设计 Agent：对照 Principal 改 Agent 的工作方式，与 Kernel 待定「改进循环」 |
| Agent Step Value（编号待补） | 同一冻结状态在不同的投影、理由、提示或评分规则下重放，评分出现符号偏移与不一致 | 对照试跑：检验结果对投影敏感 |

## 系统边界与协议

| 先例 | 观察 | 与设计的关系 |
|---|---|---|
| A2A v1.0 | AgentCard 描述能力；Task 是有状态的工作单元，含 input_required、auth_required 两个可恢复的中断态；执行不透明；身份在传输层，每一跳重新认证，不传委托链、不收窄；重新订阅时先发当前完整状态 | A2A 对应只持 Provided port 的关系；外部 A2A agent 是只有 Interface 的外部服务；input_required 对应回复里带附带 |
| MCP | tools、resources、prompts、sampling、elicitation、roots | 推断：tools 是 Port；resources、prompts 是返回 Value 的 Port；sampling 是把自己的 engine 显式授予对方；elicitation 是经 root entry 去问根的 Port；roots 是挂载的 Tree |
| ACP | 有两个：IBM 的 Agent Communication Protocol，据记忆已并入 A2A；Zed 的 Agent Client Protocol，在编辑器与 coding agent 之间 | 系统边界上的候选绑定 |
| ANP | 互不信任的智能体之间的通信协议 | 系统边界 |
